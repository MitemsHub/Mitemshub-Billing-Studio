# PROJECT BRIEF (approved: active build, 2026-11-13)
Product / audience / goal: Mitemshub Billing Studio — a freelance invoicing, client ledger, recurring billing, automated payment reminder, and custom branding web app for Mitemshub (Data Analysis, AI Engineering, Custom Web Development).
Stack and constraints: React 19 + Vite + Tailwind CSS v4 + TypeScript + Lucide icons + Motion; localStorage persistence + JSON backup/restore + A4 print stylesheet; zero fake telemetry or external unverified image URLs.
Mode: Original (with SaaS & Dashboard domain rigor)
Design direction:
- Thesis: Precision financial stationery meets editorial studio ledger — crisp paper surfaces, tabular monospace numerals, and dual-currency (USD & NGN) clarity side by side.
- Typography: Bricolage Grotesque (display), Plus Jakarta Sans (body), JetBrains Mono (tabular numerals & invoice codes).
- Palette (60-30-10): #F7F7F5 warm paper canvas (60%), #FFFFFF structural surfaces with 1px #E5E5E0 hairline borders (30%), customizable #0F5C4D Mitemshub studio emerald accent (10%).
- Signature moment: Bespoke Mitemshub SVG Logo Studio + Live Dual-Currency A4 Invoice Stationery Preview with instant USD/NGN conversion & Automated Reminder Rule Engine.
